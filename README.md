## LLM 标准执行流程（SOP）

### 阶段一：Agent 决策与选型（先选型）
> 严格依据 [`agent介绍与选择.md`](./agent介绍与选择.md) 引导，未与用户充分达成共识前，严禁直接推荐某一款或提供安装链接。

1. **网络连通性摸底（Step 0）**
   - **由 LLM 在本机宿主（非沙箱环境）直接执行**网络测试命令（检测 YouTube、Google、OpenAI 连通性）；需要提权或授权时，先执行提权或向用户索取授权，不要默认把命令丢给用户。
   - 仅在无法确认宿主/非沙箱执行模式、或未获授权时，才交由用户在本机终端运行；**严禁用隔离环境的测试结果判断用户本机网络**。
   - 根据网络状态初判路线：国际官方订阅、第三方 API / 中转站、或纯国内版。
2. **多轮需求调研（Step 1）**
   - 交互式询问核心工作场景（编程开发、文员办公、多媒体创作、资料研究、本地保密等）与偏好习惯（IDE 习惯、可视化批注、全自动化等）。
   - 不做先入为主的假设，通过 1~2 轮简洁提问与用户达成共识。
3. **精准匹配与方案推荐（Step 2）**
   - 结合各 Agent 特性给出针对性推荐（如：日常学习办公选 Qoder；重度 Office 交互选 WorkBuddy；工作流高度自定义/数据敏感选 DeepSeek Harness；复杂专业开发推荐 Claude Code 与 GPT / Gemini 搭配）。
   - 说明版本门槛（国内版 vs 海外版要求、账号与订阅难度）。

---

### 阶段二：Agent 下载与安装（后部署）
> 在用户明确认可选型后，切换至 [`agent下载目录.md`](./agent下载目录.md) 指导具体实施。

1. **版本确认**
   - 结合阶段一确定的网络与账号条件，明确指导用户使用「国内版」还是「海外版/国际版」（参考目录第 7 节差异表）。
2. **安装源判定原则（核心红线）**
   - **本地优先**：仅在本地 `入门agent部署/安装包/` 目录下**确实存在目标安装包**时，才指导本地安装。
   - **缺包指引**：若本地无对应安装包，**严禁盲目执行本地调用**，必须明确提示用户二选一：
     - **方案 A（推荐）**：下载并解压官方整合安装包到本地目录后再行安装；
     - **方案 B**：根据 [`agent下载目录.md`](./agent下载目录.md) 第 1~6 节直链自行下载（或参照 [`download_myself.md`](./download_myself.md)）。
3. **安装指导与校验**
   - **常规客户端**（Qoder、Trae、WorkBuddy、dsh、MiniMax Design）：提供对应平台直链、用户级/系统级权限提示及响应头哈希校验方式。
   - **终端型 / 国际 Agent**（Claude Code、Codex/ChatGPT、Antigravity）：引导查阅对应的专专注文档（`claude_code.md` / `codex.md` / `antigravity.md`）。

## LLM 交互行为准则

- **严禁次序颠倒**：在第一阶段选型共识达成前，切勿倾倒大段下载链接与安装参数。
- **保持小步交互**：每次回复聚焦 1~2 个关键决策点，避免单次输出信息过载。
- **尊重安全规范**：严格核实安装包来源与本地文件状态，杜绝失效路径执行。
